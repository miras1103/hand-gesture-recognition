# Demo Video Outline — 3–5 Minutes

1. **0:00–0:30 — Task:** introduce the three gesture classes, dataset size, and Assignment 1 baseline.
2. **0:30–1:10 — Method:** explain EfficientNetV2B0 ImageNet transfer learning, the frozen feature extractor and classifier head, and show the conventional-augmentation ablation setup.
3. **1:10–2:30 — App:** launch Streamlit, upload a sample image, show predicted class, all three probabilities, Grad-CAM overlay, average latency, and environment information. Optionally demonstrate camera capture.
4. **2:30–3:30 — Evaluation:** show measured Accuracy/F1 comparison, one confusion matrix, and training curves. State which values are Assignment 1 references and which were measured by Assignment 2 scripts.
5. **3:30–4:15 — Limitations and ethics:** discuss the small dataset, Grad-CAM limitations, consent considerations, and whether any synthetic data was used.
6. **4:15–4:30 — Reproducibility:** point to the README and repository instructions.

Use only actual outputs from the trained model. If the model has not yet been trained, do not record demo predictions or invent metrics.
