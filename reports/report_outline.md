# Assignment 2 Report — 6–8 Page Structure

Use measured outputs from `results/` after training. Do not present an empty result as a measurement.

1. **Introduction and task (½ page):** three gestures, intended use, problem definition, assignment objective.
2. **Dataset and baseline (1 page):** 307 original images, class counts, 128×128 RGB preprocessing, stratified split, Assignment 1 metrics from `results/baseline_reference.csv`.
3. **Method (1–1½ pages):** EfficientNetV2B0 ImageNet transfer learning; explain the frozen feature extractor, classifier head, and training augmentation.
4. **Application and explainability (1 page):** Streamlit upload/camera flow, class probabilities, Grad-CAM limitations, latency measurement protocol.
5. **Experiments and results (1½–2 pages):** use `results/assignment2_metrics.csv`, the training-curve plots, and confusion matrices. Compare baseline and measured Assignment 2 results on the documented split. Discuss Accuracy, macro/weighted Precision, Recall, and F1.
6. **Ablation and discussion (1 page):** compare the same EfficientNetV2B0 pipeline with and without training augmentation; state seed, split sizes, and epochs. Do not claim improvement unless the measurements support it.
7. **Ethics, limitations, and conclusion (½–1 page):** small and potentially non-representative dataset; unknown dataset consent provenance unless confirmed; no identity inference; avoid filming bystanders; local demo images are not saved by the app; disclose any generated data (none is created by this project unless explicitly added and labeled).
8. **Reproducibility (½ page):** Python version, Windows PowerShell commands, dependency versions, data location, model-weight download note, and repo contents.
